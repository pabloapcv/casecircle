## Excluded Data

The following data series were not included because figures could not be verified from official USCIS sources:

- I-751, I-90, I-130, I-129F processing times (median values unverified)
- I-485 employment-based processing times (unverified)
- I-131 reentry permit series (no official source)
- Field offices other than Chicago (figures unverified)
